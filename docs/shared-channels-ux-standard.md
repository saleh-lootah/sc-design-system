# Shared Channels User Experience Standard

This document has been split into three. Requirement identifiers are unchanged.

- **[Shared Channels Service Standard](standard/service-standard.md)**: the consultation draft of the requirements services are assessed against, with the requirement index and a map of where each earlier chapter went (Appendix E).
- **[Shared Channels Design System reference](standard/design-system-reference.md)**: tokens, type scale, sizes, motion, icons, components and budgets. Versioned with the library; not assessed directly.
- **[Shared Channels Assurance handbook](standard/assurance-handbook.md)**: roles, risk tiers, assessments, test scripts, exceptions, contracts and templates.

The change log is [ux-standard-changes.md](ux-standard-changes.md).
