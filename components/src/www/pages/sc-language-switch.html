Language switch

A link to the same page in the other language, named in that language and set in its own script.

Appearance

inline (app bar)
header (site header)
focus (keyboard)

No flags, never a menu (LANG-05). Fires scSwitch, cancelable for single-page apps.

In Arabic

Always lang="ar" dir="rtl": the link reads "English", set in the English type role.
