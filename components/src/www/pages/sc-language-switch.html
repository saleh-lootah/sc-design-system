Language switch

Goes to the same page in the other language. The label is the other language's own name: "العربية" on English pages, "English" on Arabic pages.

Variants

glass · href
plain · href
href · scSwitch, preventDefault (single-page app)
focus (keyboard)

Switch the preview language in the toolbar: the label, lang and hreflang change together.

Both directions

on an English page <a href="/ar/renew" hreflang="ar" lang="ar">العربية</a>
on an Arabic page <a href="/en/renew" hreflang="en" lang="en">English</a>
