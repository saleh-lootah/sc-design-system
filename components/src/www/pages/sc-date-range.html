Date range

For a start and an end date that relate to a calendar: filtering payments between two dates, the nights of a hotel stay, how long a permit lasts. For one date people already know, use a date input.

Usage

Show payments Reset

The demo fixes today at 19 October 2026 (today), with max = today, as on a payment filter. Below 600px the picker opens as a bottom sheet.

States

empty · one month · no presets
error · end before start
error · both · too long
optional · year boundary
disabled (avoid)

In Arabic

This card is always lang="ar" dir="rtl": From (من) is on the right, the arrow points left, Monday is the rightmost column and Left Arrow moves to the next day.
